# Antenna Calculator PRO for Android

**Version 1.19.269 · UA1CFM · 2026**  
[English](README_EN.md) | **Русский**

**Antenna Calculator PRO** — Android-приложение для радиолюбителей и инженеров, объединяющее анализ моделей проволочных антенн MMANA-GAL, обработку результатов электромагнитного моделирования CST/HFSS и инструменты ВЧ-измерений. Программа предоставляет входной импеданс, диаграммы направленности, распределение токов, анализ ближнего поля и дополнительные инструменты визуализации и измерений.

> **Статус:** исследовательский проект в активной разработке. Результаты расчётов следует проверять на эталонных моделях и измерениях; не все типы антенн и моделей земли имеют одинаковую степень численной точности.

## Возможности

### Анализ MMANA-GAL (`.maa`)
- Открытие моделей проволочных антенн с источниками, нагрузками и настройками земли.
- Расчёт комплексного входного сопротивления **Z = R + jX**, КСВ и связанных параметров.
- MMANA-совместимый **MININEC-решатель** на Kotlin: токи, импеданс и исходные данные для ДН.
- Поддержка нескольких когерентных источников, специальной адресации импульсов `W#E`, комбинированных проводов (CombWire) и моделей Make Stack.
- Работа с моделями Yagi, решётками, вертикальными антеннами, петлями и другими геометриями — с оговоркой о необходимости численной проверки сложных случаев.
- Опциональный учёт омических потерь проводников из меди или режим PEC.
- Пакетная обработка моделей и экспорт диагностических данных/результатов в CSV.

### Диаграммы направленности и 3D
- 2D ДН, основные сечения и показатели направленности.
- 3D ДН с наложением на геометрию антенны: проводники, источники и нагрузки остаются видимыми.
- Полупрозрачная поверхность ДН с различием ближних и дальних граней при вращении.
- Отрисовка и экспорт изображений PNG; интерактивный просмотр геометрии.
- Отображение фаз и распределения токов, режимы фазовой анимации.

### Поле, фазовые характеристики и анализ облучателей
- Визуализация ближнего электромагнитного поля, включая компоненты E/H и производные величины при поддержке конкретного режима.
- Импорт дальнего поля **CST `.ffs`** и **Ansys HFSS `.ffd`**.
- Анализ диаграмм, фаз и параметров облучателей/рефлекторов по данным моделирования.
- Инструменты для Smith Chart, частотных развёрток и анализа согласования.

### Измерения и вспомогательные инструменты
- Поддержка **LiteVNA64** по USB (при наличии совместимого устройства, разрешения Android USB Host и подходящего кабеля/OTG).
- Работа с S-параметрами, S11/S21, КСВ, маркерами, частотными развёртками и файлами Touchstone.
- Измерительные и вспомогательные режимы, включая TDR и экспериментальное аудиопредставление ВЧ-данных.
- Радиолюбительские расчёты и преобразования физических величин.

## Расчётное ядро: важное замечание

В актуальной ветке **основным решателем для импеданса MAA является MMANA/MININEC**, а не старый NEC-2 FULL. Некоторые файлы с названием `Nec2*` остаются в дереве исходников для вспомогательных функций и совместимости. Само наличие таких классов не означает, что NEC-2 FULL является текущим основным решателем.

Численная близость к MMANA-GAL **не гарантирована** для всех моделей. Особого внимания требуют реальная земля, LC-нагрузки, точки соединения проводников и многопортовые конфигурации. Параметры входного сопротивления никогда не следует считать достоверными только по факту успешного завершения расчёта.

## Новое в 1.19.269

- Допуск соединения близко расположенных концов проводников в MININEC установлен не менее **10 мкм (1×10⁻⁵ м)**, согласованно с изменениями Windows v0.4.8.
- Для 3D ДН изменено визуальное разделение ближних и дальних полупрозрачных граней; обновлён также экспорт PNG.
- Сохранены существующие обработка `W#E`, ориентация источника и многопортовая логика — без необоснованной замены математического ядра.
- **Не переносилось:** отдельное C#-ядро Windows `MmanaReferenceEngine`, а также Windows glass-растеризатор в его исходной реализации.

## Системные требования

- **Android 7.0 (API 24)** и новее; целевой API — 35.
- Для работы с LiteVNA64: поддержка USB Host/OTG и совместимое USB-устройство.
- Для сборки из исходников: **Android Studio**, Android SDK 35 и совместимая JDK (Gradle-проект использует Java/Kotlin target 17).

## Сборка

1. Скачайте и распакуйте полный архив исходного кода.
2. Откройте корень проекта в Android Studio (в нём находятся `settings.gradle.kts`, `build.gradle.kts`, `app/` и `gradlew.bat`).
3. Дождитесь Gradle Sync; установите SDK 35 при запросе.
4. Выберите модуль `app` и выполните **Build → Build APK(s)** либо `gradlew.bat assembleDebug` в Windows.
5. Установите полученный APK на Android-устройство и предоставьте необходимые USB-разрешения для внешнего анализатора.

Идентификатор приложения: `ua1cfm.cstffs`. Номер версии: **1.19.269** (`versionCode 119269`).

## Проверка и известные ограничения

- Доработки 1.19.269 проверены по структуре исходного кода; полная сборка Gradle и испытания на устройстве **не были подтверждены** при подготовке этой версии.
- Полного численного соответствия Windows `MmanaReferenceEngine` и Android Kotlin MININEC пока не подтверждено.
- Некоторые сложные антенны с реальной землёй, LC-нагрузками или нестандартной сегментацией могут показывать заметные расхождения с MMANA-GAL.
- Модели **Coil vertical**, Yagi с нагрузками, Make Stack и антенны с несколькими источниками рекомендуются как контрольные для дальнейших регрессионных проверок.
- Наличие функции в интерфейсе не заменяет метрологическую проверку измерительного тракта и калибровки.
